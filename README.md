# Road Accident Analysis Dashboard | Excel

## Project Overview
This project focuses on analyzing road accident data using Microsoft Excel to identify accident patterns, understand contributing factors, and provide insights that can support road safety improvements.

## Tools & Skills
- Microsoft Excel
- Data Cleaning
- Pivot Tables
- Data Analysis
- Interactive Dashboard
- Data Visualization

## Key Performance Indicators (KPIs)
- Total Accidents
- Total Casualties
- Fatal Casualties
- Serious Casualties
- Slight Casualties
